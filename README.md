# Vasavi Kosaraju

I’m interested in how AI applications are built, deployed, and kept reliable. This is where I’m developing projects around retrieval, deployment checks, and cloud planning.

## Projects

- **[Runbook Search](https://github.com/VasaviKosaraju1/runbook-search)** — An offline search tool for operational notes. Uses BM25 ranking, returns source references, and includes a small retrieval evaluation.
- **[Release Preflight](https://github.com/VasaviKosaraju1/release-preflight)** — A command-line checker for Kubernetes Deployment JSON. Reports common configuration issues before a release.
- **[Cloud Budget Planner](https://github.com/VasaviKosaraju1/cloud-budget-planner)** — An offline calculator for infrastructure scenarios, with explicit pricing assumptions and budget checks.

Each repository includes runnable examples, tests, and notes on the design and its limits. These are portfolio projects; I’m building on them as I learn and explore new approaches.
