# Hi, I’m Vasavi 👋

My current focus is **DevOps and Cloud Engineering**: automating delivery, managing infrastructure as code, and making systems easier to operate. I’m also interested in **AI/ML**, particularly information retrieval, evaluation, and the engineering that helps AI applications run reliably.

This GitHub brings together practical portfolio projects with working examples, tests, and clear notes on the decisions behind the code.

I’m exploring how to find useful information and measure the quality of the results. These projects are my starting point:

| Project | Focus |
| --- | --- |
| [Runbook Search](https://github.com/VasaviKosaraju1/runbook-search) | BM25 document retrieval, source references, and a reproducible evaluation |
